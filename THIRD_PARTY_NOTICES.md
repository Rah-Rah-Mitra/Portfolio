## Stacked project carousel

The Project Archive showcase adapts the "carousel-07" stacked-card drag carousel pattern published on shadcnspace/21st.dev community components (MIT-licensed component snippets), rebuilt on the `motion` animation library with project-specific slides, activation, and accessibility controls.

## Electric Gaze ASCII effect

The ASCII desktop background re-implements the "Electric Gaze" ASCII-art look from the 21st.dev community ASCII editor as an original Canvas2D engine (`lib/ascii/electricGaze.ts`); no source code was copied. The reference photograph at `public/ascii-editor/demos/generated/ref-002.webp` is an original synthetic composition rendered for this repository.
