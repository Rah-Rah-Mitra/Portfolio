# Interactive optical test bench: interaction matrix

Recruiter evidence remains semantic HTML at each response target. The optional scene treatment can never be the only way to read project facts, equations, contact details, or resume links.

## Workstation shell

| Interaction | Purpose | Input | State and feedback | Reset / fallback | Coverage |
| --- | --- | --- | --- | --- | --- |
| Application module | Open a named evidence or lab surface | Pointer, touch, Enter, Space | One module latches into the active bay; the prior module becomes minimized | Minimize or Escape returns Home and restores trigger focus; anchors remain in static rendering | `workstation.test.ts`, `workstation.dom.test.tsx` |
| Window controls | Reframe a technical tool without moving evidence | Pointer, touch, labelled keyboard controls | Bounds clamp to the usable viewport; left/right/maximize states are explicit | Mobile uses a full-screen sheet; Quick Scan has no window controls | `workstation.test.ts`, browser acceptance |
| Browser history | Share and revisit a focused application | URL, Back, Forward | `?app=` follows the active module and preserves unrelated query/hash state | Invalid apps resolve to Home; `?mode=scan` suppresses workstation state | `workstation.test.ts`, `workstation.dom.test.tsx` |

## Technical exhibits

| Scene | Purpose / model | Primary manipulation | Secondary detail | Ambient motion / character reaction | Controls and reset | Reduced motion, Quick Scan, and no-WebGL fallback | Response target | Test coverage |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Calibration | Orient the visitor with the Optical Courier arrival model. | Choose Guided Story or Explore. | Read the evidence index and journey cue. | A restrained calibration field; Courier idles. | Mouse/touch select; keyboard focus and Escape return to Guided Story; Reset restores Guided Story. | Static overview with all evidence links; no video or canvas required. | `#home` | Semantic overview, Quick Scan, reduced motion. |
| Systems in Motion | Explain a fixed 3-job/2-machine permutation flow-shop. | Reorder jobs. | Completion times, idle time, critical operation, accessible Gantt table. | Input-driven schedule transition; Courier inspects the selected schedule. | Mouse drag/click, touch reorder, keyboard reorder; Escape cancels; Reset restores the documented order. | Ordinary schedule table and explanation. | `#experience` | All six permutations, keyboard/touch parity, table fallback. |
| Spatial Systems | Explain a synthetic site-allocation marker and route. | Move the synthetic marker. | Layer visibility, distance, nearest eligible plot, route. | No idle movement by default; Courier points to an eligible plot. | Mouse/touch marker controls, keyboard alternative, Escape cancels; Reset restores marker and layers. | Form and data-table explanation with non-proprietary disclaimer. | `#all-work` | Geometry, touch parity, table fallback. |
| Selected Work | Connect optional interaction to factual project evidence. | Scrub a pipeline or expand architecture detail. | Ordered diagrams, outcomes, proof links. | Optional restrained detail transition; Courier inspects active evidence. | Mouse/touch scrub, keyboard controls, Escape cancel; Reset collapses optional detail. | Ordered semantic diagrams and project links stay visible. | `#work` | Ordered diagrams, Reset, links. |
| Camera Laboratory | Teach intrinsics, extrinsics, optics, and stereo as a labelled experiment. | Adjust one camera variable. | Presets, equations, and computed results. | Paused when constrained; Courier calibrates the active mode. | Mouse/touch inputs, keyboard adjustments, Escape cancel; independent Reset restores the documented preset. | Equations, results, and disclaimer in HTML. | `#technical-lab` | Pure math, presets, keyboard controls, semantic fallback. |
| Departure | Acknowledge completion without gating handoff actions. | Replay the optional iris treatment. | Contact and role-targeted resume links. | Optional iris only; Courier signals handoff. | Mouse/touch Replay, keyboard focus, Escape cancel; Reset stops the treatment. | Visible static contact and resume actions. | `#contact` | Visible actions, Replay, reduced motion. |

Control ownership is explicit: narrative controls story position, visitors control only documented exhibit parameters, and the system may reduce quality or select a fallback. Visitor input always wins over ambient motion while an exhibit is active.
