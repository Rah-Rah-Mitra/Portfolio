# Retro Optical Workstation

The enhanced portfolio is a precision-retro workstation whose controls correspond to real portfolio surfaces. It is not a game and it never replaces the semantic evidence document.

## Experience contract

- Home / Dossier launches as the normal recruiter-facing document and keeps identity, current proof, resume, profiles, and contact actions in the first view.
- Ten application modules occupy one instrument rail. Only one application owns focus at a time; inactive modules remain available as minimized taskbar entries.
- Home uses document scrolling. Tool applications use a single bounded scroll surface and restore the prior Home position when minimized.
- `?app=<id>` identifies an open tool. `?mode=scan` always wins and suppresses workstation, WebGL, and video enhancement.
- On desktop, tools can move, resize, maximize, and snap. On tablet and mobile they become full-screen sheets with no precision dragging.
- Server rendering emits the complete evidence order. Before enhancement or without JavaScript, every application surface is ordinary document content.

## Mechanical language

The rail is a functional selector assembly: socketed modules, an active carriage, state lamps, fasteners, calibration ticks, and bounded readouts. Opening a module latches it into the active bay; minimizing returns it to the rail. Mechanical motion explains state and never animates reading copy.

Application icons are raster renders of real modeled objects. Primary technical demonstrations use interactive GLB geometry or rendered media, not pictorial SVG substitutes. HTML and CSS remain responsible for semantic chrome and controls.

## Media and truthfulness

- The production Courier is accepted only after Mixamo rigging, Blender normalization, deformation checks, clip inventory validation, optimized GLB export, and browser playback.
- Generated video is conditioned by deterministic start/target renders and ships only after artifact review.
- Rejected generations and unrigged meshes remain provenance artifacts and are never represented as public production media.
- Total shipped visual/audio media is capped at 15MB; Quick Scan attaches no heavy sources.
