# Deferred synthetic SLAM study

These deterministic OpenCV outputs are retained as non-public research support.
They are not copied into the production site and must not be presented as a
professional project or a completed RADIO/BiRefNet benchmark.

Regenerate experiments with `scripts/perception/build_synthetic_study.py`. New
outputs go to ignored `artifacts/deferred-slam-study/` so a benchmark must pass
the documented reproducibility and evidence gates before selected assets are
explicitly promoted into `public/`.
